# Context Menu Feature Guide

## ✨ New Features Added

Your music player now has a powerful context menu system! Long-press any song to access quick actions.

## 🎵 How to Use

### Long Press a Song
1. **On any song** in the Home or Library screen
2. **Press and hold** (long-press) for 1 second
3. **Context menu appears** with options

## 📋 Menu Options

### 1. Play Next ⏭
- Adds the song to play immediately after the current song
- Perfect for "I want to hear this next!"
- Queue stays intact, song just jumps to front

### 2. Add to Queue ➕
- Adds the song to the end of your current queue
- Great for building a listening session
- Song plays after all queued songs finish

### 3. Add to Playlist 📋
- Opens playlist selector
- **Create New Playlist** option at the top
- Select existing playlist to add song
- Shows song count for each playlist

### 4. Add/Remove from Favorites ♥/♡
- Toggle favorite status
- Filled heart (♥) = already favorited
- Empty heart (♡) = not favorited
- Access favorites from Home tab

## 🎶 Playlist Management

### Creating a Playlist
1. Long-press a song
2. Tap "Add to Playlist"
3. Tap "Create New Playlist"
4. Enter playlist name
5. Tap "Create"
6. Song is automatically added!

### Adding to Existing Playlist
1. Long-press a song
2. Tap "Add to Playlist"
3. Browse your playlists
4. Tap the playlist name
5. Song is added instantly!

## 💡 Tips & Tricks

### Quick Favorites
- Long-press → Favorite
- Fast way to build your favorites collection
- Access from Home > Favorites tab

### Building Queues
- Use "Play Next" for immediate priority
- Use "Add to Queue" for later playback
- Mix and match to create perfect listening flow

### Organizing Music
- Create themed playlists (Workout, Chill, etc.)
- Long-press makes playlist building fast
- Songs can be in multiple playlists

### Navigation
- **Back button** in playlist selector returns to main menu
- **Tap outside** menu to close
- **Tap Cancel** in create dialog to abort

## 📱 User Flow Examples

### Example 1: Quick Favorite
```
1. Browse songs
2. Long-press "Amazing Song"

```

### Example 2: Create Workout Playlist
```
1. Long-press first workout song
2. "Add to Playlist" → "Create New Playlist"
3. Name: "Workout Mix"
```

```
1. Start playing a song

```

## 🐛 Troubleshooting

### Menu Not Appearing
- Try longer press (hold for 1+ seconds)
- Ensure you're pressing the song, not scrolling
- Check app is responsive

### Can't Select Playlist
- Ensure you have playlists created
- Try "Create New Playlist" first
- Check playlist list scrolls if many exist

### Actions Not Working
- Check Metro bundler is running
- Look for errors in console
- Try restarting the app
